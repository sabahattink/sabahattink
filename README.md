## How I Build

- **Deterministic first.** Collect evidence with plain code, then let the model interpret it.
- **Local by default.** No account, no server, no telemetry unless the problem needs it.
- **One command to value.** If it needs a setup guide before it's useful, it isn't done.
- **Built for real operating environments.** Observable, testable, failure-aware — the habits of field commissioning, applied to software.

**Useful beats impressive. Deterministic beats magical. Shipping beats collecting unfinished ideas.**
